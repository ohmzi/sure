**(Ruling M5-L1, 2026-10-11.)** When the rebase re-checks `data_importer.rb`, verify the

re-adopts upstream's raw assignment must re-apply it.

## Procedure

1. `git fetch upstream` (remote = `we-promise/sure`); note the new tip.
2. `git switch -c rebase/<date> origin/main` then `git rebase upstream/main`.
3. Resolve conflicts **only** in the contact-surface files below; for every other
   conflict, prefer the additive fork file and re-derive.
4. Run the full battery: `bin/rubocop`, `npx biome check`, `bundle exec erb_lint app`,
   `bin/brakeman`, `bin/rails test`, `DISABLE_PARALLELIZATION=true bin/rails test:system`.
5. Smoke the stack (`deploy/dc up -d`, `/up` 200) and the acceptance script's steps 3–8.
6. Merge to the fork's mainline with a conventional commit
   (`chore: rebase onto upstream <sha>`).
